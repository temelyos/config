# @temelyos/config

> 🛠 Unified configuration package for all Temelyos projects

This monorepo config package bundles and exposes shared configurations for:

- ✅ ESLint
- ✅ TypeScript
- ✅ Oxlint

Use it to enforce consistent tooling across all frontend, backend, and shared workspaces in the Temelyos ecosystem.
